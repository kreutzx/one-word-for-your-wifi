## The word

> **Liar**

## Why this word

Home Wi-Fi never fails honestly. It shows full bars, says "Connected", and then loads nothing — mid-call, mid-video, in the one room you actually need it. It does not drop; it lies to your face. One word, four letters, no setup and no explanation needed: the whole joke is the word itself, and as a network name it is the confession the router deserves.

## How it works

`main.py` (Python standard library only) writes the entry word to `/output/entry.txt`.
